# 网络服务会话失效排查与回归（2026-11-09）

## 证据

用户截图显示 `helper lease renewal failed; recovery is owned by the service: owner session is stale or invalid`。
本机应用日志当天多次记录 `/magic` 握手 50ms 超时，并在 15:08:34、15:16:39、15:19:50 记录旧会话被拒绝。日志证明握手失败和会话失效发生过；缺少对应 helper 日志，不能据此认定每次失效的唯一原因或确认都由睡眠触发。

代码存在两个风险：续租请求虽有独立超时，前置握手仍使用通用 50ms；睡眠后的 10 秒宽限可能覆盖并缩短尚有更多剩余时间的租约。

## 当前修复

保留并验证工作区原有未提交修复：续租握手使用 750ms 预算，整体心跳保持 3 秒上限；唤醒宽限不缩短原到期时间；明确失效的凭据停止续租，使用带原会话代次的条件重连；服务仅允许已自然过期的原 owner 重连，不覆盖新会话或手动停止；最多三次启动尝试，无活动网络时等待网络恢复；退出和恢复共用写锁。

本轮补充：为条件重连定义独立能力版本常量，并检查版本响应成功；中文提示区分暂时连接失败、会话重连和需要清理的状态；补测其他 owner、错误代次不可重连，以及活动状态读取异常恢复后原会话仍可正常续租。

自动重连要求 helper revision 14；revision 13 仍兼容常规操作，但需在网络设置中安装 / 修复新版服务才能使用条件重连。
