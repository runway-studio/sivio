# App 发布构建体积优化

原包 `20261030-150723-6c34ad49` 按文件字节合计约 310.03 MiB，ZIP 152.40 MiB。主程序约 158.17 MiB，五个辅助程序合计约 44.35 MiB；完整随包源码约 61.36 MiB，双 Mihomo 内核压缩资源约 39.81 MiB。

根因是 `scripts/build-app.py` 固定使用 Cargo dev 与 Tauri `--debug`，没有应用主程序已有的 release 体积优化配置。

## 调整

- 默认构建 release；显式 `--debug` 仍可生成开发调试包。`--skip-helper-build` 仅复用所选 profile 下的辅助程序，不会混用 debug/release。
- 主程序沿用现有 `opt-level = "s"`、thin LTO、符号剥离与 unwind 配置；辅助程序统一使用体积优化和符号剥离，保留原已交付 debug 构建的 unwind 语义。
- 功能代码、Cargo features、前端入口与功能资源未删减。保留稳定/Alpha 双内核、全部五个辅助程序、许可证和完整随包源码。
- 继续生成独立不可变 App 目录，并沿用原签名身份。新增构建 profile、App 文件字节总量和 ZIP 字节量到产物报告。

## 验证记录

`scripts/validation/test-bundle-publication.py` 两项通过，包括正在运行的旧构建在发布新构建后仍保持有效签名。

原包体积清单保存在 `build/reports/app-size-before.json`；本次构建日志在 `build/reports/app-size-build.log`，最终体积、资源保留与签名校验结果在 `build/reports/app-size-verification.json`。MiB 按 1024² 字节计算。
