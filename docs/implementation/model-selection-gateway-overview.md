# 模型选择持久化与网关总览

日期：2026-10-19。本轮用户授权：参考 Magpie 优化模型选择与路由，修复 `/model` 切换后重启回退，实现参考图片的界面并重新打包。

## 最终行为

- 路由初始化将供应商的有效默认模型写入 Claude Code 的顶层 `model`，接管配置不再写 `ANTHROPIC_MODEL`，避免遮住 `/model` 保存的选择。直连供应商行保留原始配置。
- 本机 `live-state.json` 的 `claude_selection` 分别记录每个供应商在路由和聚合模式中的选择；不写回供应商数据库、不参与云同步。Sivio 退出前捕获选择，启动接管时恢复；异常退出后重新接管也读取客户端当前选择。
- 客户端选回 Default（移除 `model`）同样保留。只改凭据或固定角色不会重置主模型；实际修改供应商默认模型时使用新默认。
- 路由与聚合选择互相隔离。聚合成员被移除时，已失效的聚合模型选择回到默认。
- 已保存的明确模型请求优先原样转发，避免被名称中的 sonnet 等字样或默认兜底再次替换。角色别名继续按既有映射处理。
- 选择记录和配置变更共同进入 pending 操作，崩溃恢复一起落定。读到选择之后出现外部修改时拒绝覆盖。即使契约相同，Claude 切换也需要读取选择；文件不可读时拒绝切换，恢复读取后可重试。
- 模型页展示 Claude Code 实际保存的模型，定时刷新；帮助文字说明初始默认、`/model` 选择和退出恢复的区别。

## 界面

首页新增“客户端 → Sivio 网关 → 供应商”的三栏总览，参考用户提供的构图，复用当前主题、品牌和导航。

- 客户端显示真实模式、供应商或保存模型；点击进入该客户端配置。
- 网关显示运行状态、监听地址、已有的 Chat / Responses / Messages / Gemini 协议；点击可进入路由设置或 MCP 管理。
- 供应商按 API 密钥、订阅账号、本地模型分组，展示已配置条目；没有条目时提供添加入口。
- 连线是配置关系，不是实时请求动画或上游健康证明。只有服务运行且客户端已接管时显示实线；直接接入供应商的客户端不冒充已通过网关。
- 客户端、网关、供应商始终保持三栏同排。内容区不足 820px 时只压缩间距、卡片内边距，并将客户端模式放到名称下方，不切换为两栏或单栏。960px 应用最小窗口、侧栏展开时三栏仍完整可见；低于应用支持尺寸时，总览区域可局部横向滚动。
- 连接线按卡片边缘中心计算，使用 ResizeObserver 跟随窗口、侧栏、文本换行变化；两侧连线始终保留。

没有新增截图中所有第三方产品的集成，也没有将未实现的插件中间件显示为已支持。总览复用项目已有能力。

## 默认三栏修复复验（2026-10-19）

用户明确要求默认三栏；上一版断点测试接受两栏，因此虽然没有溢出，仍不符合预期。本次移除所有改变列数、将供应商下移和隐藏连接线的规则，改用紧凑三栏。总览最小内容宽度 516px，避免极窄区域挤坏卡片；应用支持的窗口范围内无需横向滚动。

- 234 组真实外壳浏览器布局通过，包含 960px 最小窗口、1021px 截图对应逻辑宽度、1280px 默认宽度，侧栏两种状态，中英日、长名称和空配置。
- 断言改为每组都必须三栏左右依次排列且纵向重叠，两侧连线均显示并与卡片中心对齐；窗口宽度不小于 960px 时总览没有横向滚动。导航检查通过。
- 组件测试 3 项、类型和格式检查通过；截图人工检查覆盖浅色 960px、深色 1021px 的实际侧栏布局。
- 新证据：`build/reports/gateway-three-column-browser.json`、`gateway-three-column-fixture/`、`gateway-three-column-light-960.png`、`gateway-three-column-dark-1021.png`。
