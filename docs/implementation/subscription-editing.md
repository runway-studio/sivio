# 订阅编辑功能（2026-10-19）

本次范围对应用户提供的 Clash Verge 订阅菜单、全局扩展卡片及可视化规则编辑截图。对照仓库固定的 `vendor/upstream/clash-verge-rev/src/components/profile` 源码，复用已有增强管线，新增 Sivio 界面入口。

## 使用入口

网络 → 订阅 → 卡片右上角「…」，或右键订阅卡片。

- 使用、编辑信息、编辑文件、编辑规则、编辑节点、编辑代理组。
- 订阅扩展覆写配置、扩展脚本；列表下方提供全局覆写和全局脚本。
- 远程订阅可分享本地生成的二维码、复制订阅地址、直连更新、代理更新。
- 打开文件使用默认文本编辑器打开私有工作副本；点击「读取外部修改」后再保存才生效。
- 活跃订阅禁止删除；其他删除仍经已有确认流程。

## 配置语义

可视化规则编辑支持类型、内容、策略、前置/后置、搜索（大小写/正则）、上移、前后置转换、删除和恢复。节点及代理组支持表单与完整 YAML 对象，高级 YAML 可编辑整段增强。无法在表单完整表达的规则会转向高级编辑并提示，避免丢弃额外参数。

增强配置独立于远程 YAML 保存，更新订阅仅替换原始正文，保留增强、请求选项等。直接修改原始 YAML 则可能被下一次远程更新覆盖。前置先匹配，后置位于原始规则后，已有 MATCH 时后置规则可能不会命中。

运行中保存当前订阅和切换订阅均先验证最终配置，再应用；失败沿用已有事务恢复原配置和运行状态，保留其他应用已接管的系统代理状态。编辑使用 revision 检查，保存冲突保留草稿。替换同名节点保留所有代理组的引用。

更新菜单仅为本次操作选择直连或代理，不覆盖订阅保存的下载策略；代理更新优先使用运行中的本应用内核，否则使用系统代理。
