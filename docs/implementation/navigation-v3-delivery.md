- 二级展开 218 px、收起 72 px；一级 84 px。正式前端 960×720 下实测内容宽 658 px、文档宽 960 px，无整页横向溢出。新窗口默认 1280×900，保留旧窗口位置偏好。
- 导航共用现有未保存提醒、进行中操作锁和托盘入口。页面卸载停止显示层查询，不改变底层网络/AI 服务。

- 修复构建脚本未显式启用内置资源协议的问题：`custom-protocol` feature 显式连接 `tauri/custom-protocol`，打包命令强制启用。原生窗口确认加载 `tauri://localhost`，无需 Vite 开发服务器。
