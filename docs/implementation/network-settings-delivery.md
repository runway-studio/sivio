# Clash 网络设置独立化与能力补齐

2026-10-16；本轮属于已批准 F24 高级网络设置的补齐，用户明确要求直接改进并将混合代理端口设为 7890。

## 交互与生效范围

网络 → 网络设置采用功能列表；端口、TUN、系统代理、LAN、DNS 覆写、IPv6、统一延迟、日志等级、内核/模式、控制器/面板、测速/连接、连通检测、配置增强分别打开独立弹窗，单独保存或取消，失败保留草稿。运行期间可查看，停止后保存，下次启动应用。外部修改仍按 revision 冲突拒绝，不覆盖；可关闭弹窗后重新载入。

AI 出站策略移至应用设置 → 本地路由，只调用 outbound.set；网络弹窗只调用 settings.save。两者互不提交对方配置。主题、启动等 App 通用偏好继续共用宿主，未复制出第二套互相冲突的全局偏好。

混合代理默认 7890；旧版本 15722 在读取时按一次性版本规则迁移；已有其他自定义端口保留。关闭的 SOCKS/HTTP/Redir 为 0，可分别启用，默认候选 7898/7899/7895。混合端口始终启用以服务 SI Assist 受管出口。占用时沿用启动预检失败，不结束其他 App；当前实际监听端口仍由运行状态显示。正在运行的内核不被静默重启。

IPv6、统一延迟、日志等级、TUN stack/MTU 写入最终配置并在所有增强之后生效；非法日志级别、协议栈和 MTU 会被后端拒绝。DNS 覆写关闭时保留订阅 DNS，打开使用已编辑的全局 DNS；订阅单独 DNS 来源选择仍优先。LAN 默认关闭，继续要求认证；控制接口保持本机私有。Helper 协议未改变。
