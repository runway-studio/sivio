# 网络断线调查、启动恢复与接入入口调整（2026-10-30）

## 证据与原因

只读进程检查时，Sivio GUI 仍运行，自有 Mihomo 已不在；Clash Verge 内核运行，macOS HTTP/HTTPS/SOCKS 为 127.0.0.1:7890。未改写用户系统代理或停止 Clash Verge。特权服务目录不可读，GUI 自动化超时，无法还原本次断线时间线，不能将代码风险当作本次断线的确定原因。

代码确认两项续租风险：GUI 每 5 秒续租依赖网络 runtime 锁，而节点控制、恢复选择、日志及生命周期操作也持有该锁；排队可耗尽 helper 的 30 秒租约。续租 IPC 还使用通用 50ms 超时，磁盘同步或调度抖动会产生误报。helper 租约过期会停止内核并恢复自己仍拥有的系统代理；海外浏览器访问因而可能失败。

启动逻辑此前固定关闭 TUN、暂停系统代理，只准备内核，与用户期待的浏览器网络恢复不符。

## 实施

- 受管会话创建后立即启动独立续租任务，不等待 runtime/write 锁；3 秒有界 IPC，每 5 秒续租。保留服务端租约与鉴权，不延长崩溃后的清理窗口。会话清理后取消任务，结果由原有监控循环展示，不带旧结果修改新代次。
- 本机 resume-network.json 记录显式启动/停止意图，不进入配置备份或同步。正常退出清理不写入停止意图；主动停止后下次不启动，成功手动启动/快捷开启重新允许恢复。无旧记录沿用自动准备行为。
- 启动恢复已保存的系统代理/TUN 设置；服务已授权且系统代理为空或属于当前配置时自动应用。检测到外部代理、读取失败、服务不可用或自定义远程代理需要确认时，保留普通内核准备并暂停特权接管，不后台弹授权。
- 概览接入入口移入 AI 工具区，与安装管理并列，文案简化为“接入引导”；“继续接入”归入侧栏，支持折叠及原有未保存变更保护，不再悬浮遮盖内容。

## 触发场景补充与定向复验

用户补充：断网发生在切换节点或更新订阅时。节点切换在 runtime 锁内先读取当前选择再提交新选择；订阅更新下载和校验后会停止、重启当前配置的内核，并恢复保存的节点。该场景与已修复的续租锁争用风险一致，但缺失历史服务日志仍无法证明本次断线的唯一原因。更新活动订阅的重启可能中断已有连接，不应解释为长期无法重新连接是正常行为。

补跑已编译测试程序中的两项隔离真实内核测试，均通过：
- network-switch-real-delay.log：真实节点测速期间运行锁可用、保留手动固定选择、拒绝旧代次测速结果。
- network-switch-real-rollback.log：真实内核配置切换后本机代理请求成功，注入提交失败与启动失败后回滚旧配置，流量重新可用；真实占用及无效 DNS 配置不停止旧内核。该测试验证普通 supervisor 路径，不替代特权 helper/TUN 实机验收。

另有既有 subscription_restart_and_rollback_preserve_proxy_suspension fixture 通过，覆盖订阅重启/回滚不抢占外部代理。上述补验没有修改应用代码或替换已交付安装包，不属于用户真实订阅/公网节点测试；此前 3 项忽略中已补验 2 项，剩余为流量采样性能基准。
