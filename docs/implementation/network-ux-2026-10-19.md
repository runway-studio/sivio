# 网络使用体验修复（2026-10-19）

## 行为

- 流量页在网络工作区内保持挂载，切换标签保留 SVG、动画状态和数据。最近 60 个采样按 QueryClient 和内核代次共享，整页卸载后返回也可立即显示历史。隐藏页暂停轮询和动画，重新进入后继续；内核换代不混用历史。
- 成功初始化且存在活动订阅后，自动准备网络内核。后台不请求服务安装授权、不启动 TUN、不抢占现有系统代理；可用服务运行受管内核，否则先用普通内核。用户打开系统代理/TUN 时按需授权、应用；正常使用不需要额外点“启动网络”。
- helper revision 13 在根权限安装时登记固定签名证书及严格 desktop identifier。保留原 CDHash 验证用于旧客户端，证书登记仅信任 desktop 标识，不扩大到 validation 标识。应用后续同证书重签更新无需重新登记。
- 旧版 helper 升级到 revision 13 仍需一次 macOS 安装授权；以后服务正常时不出现修复提示。拒绝按需授权不反复弹窗，保留先前可用内核。端口冲突不误报为服务安装问题。
