# 三栏工作台 V2 落地记录

日期：2026-11-11。依据用户确认的 V2 设计，完成概览、网络首页及模型选择页的实现。保留 DomainRail / Sidebar / WorkspaceFrame，未修改三栏布局组件和导航层级；本次为源码与 renderer 交付，未打包安装或发布原生应用。

## 页面与操作

- 概览显示网络状态、当前节点、连接方式、常用 AI 工具、配置运行信息及用量；超过四个工具可以展开。工具入口直接进入对应客户端的模型页，低频诊断折叠展示。
- 概览与网络首页复用可搜索节点选择器。写入携带运行 generation、防重复提交，失败保留原观测选择和重试入口；写入成功但刷新失败单独提示。弹窗关闭恢复触发按钮焦点。
- 网络检测仅在点击后请求现有 Apple 检测目标，结果明确限定目标。配置/运行变化、写入、失焦、网络事件或 60 秒过期会使证据失效；过期异步响应不能覆盖新状态。运行中不等于网络或模型已验证成功。
- 模型页展示已保存配置、供应商/模型选择、自定义模型、现有全局 AI 出站方式和真实客户端就绪状态。保留目录搜索、路由组、revision 写入保护和失败草稿；切换客户端先确认放弃修改，保存中阻止重复提交及离开。
- 复用既有启动/停止、订阅更新、代理设置、显示偏好、模型保存和诊断接口；不增加自动恢复或后台付费探测。
