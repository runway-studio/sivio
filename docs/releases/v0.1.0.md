# Sivio v0.1.0

面向 macOS Apple Silicon 的首个 GitHub 发行版。

- 新增官方更新源、更新说明、下载验证、确认安装重启，以及高级自定义/禁用更新设置。
- 更新包执行签名、产品、版本和架构校验；更新前保护未保存改动并清理自有网络。
- 保留客户端接入与诊断、网络恢复、内置双内核离线运行及精确对应源码交付。

本版使用稳定内部签名，尚未 Apple 公证，首次安装可能出现系统安全提示。仅支持 Apple Silicon；Intel 未列入首批支持。

已有默认无更新源的内部 0.1.0 用户需手动安装此版；后续更高版本可在设置 → 关于中升级。同版本首次替换不属于自动升级。

项目完整原生功能验收仍按各功能验收记录追踪，发行不代表所有历史提案均已完成。下载资产中的 SHA256SUMS 可用于校验，对应源码包随本版本提供。
