# Sivio v0.1.1

面向 macOS Apple Silicon 的公开发行清理版本。

- 清理开发环境信息，源码包仅收录 Git 跟踪的构建输入，并统一归档用户/组元数据。
- 构建和上传前扫描源码、历史、安装包、更新包及源码归档中的敏感内容。
- 继续提供官方更新检查、签名校验、确认安装和重启；保留更新前的数据目录及旧 App 恢复副本。

本版使用稳定内部签名，未做 Apple 公证。仅支持 Apple Silicon。旧内部 0.1.0 如未配置官方源，需先手动安装；已安装官方发行版的用户可检查更高版本。

测试运行和具体覆盖范围见项目中的 release/update acceptance 记录；不将系统代理验证等同于 TUN 或 Intel 验收。
