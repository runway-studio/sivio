# Sivio v0.1.2

新增 DMG 拖拽安装包，并修复运行中的 App 文件被删除时的网络服务错误提示。

## 安装（Apple Silicon / M 系列 Mac）

1. 下载 `Sivio-0.1.2-aarch64.dmg` 并打开。
2. 完全退出旧版 Sivio，将 `Sivio.app` 拖到 `Applications`，等待复制完成。
3. 推出 DMG，从“应用程序”打开 Sivio。不要从磁盘映像或临时构建目录运行。
4. 本版保留内部签名，**没有 Apple 公证**。若被系统拦截，请确认下载来自本仓库，再前往“系统设置 → 隐私与安全性 → 仍要打开”，亲自完成系统确认。DMG 不会绕过 macOS 的安全检查。
5. 首次使用系统代理或 TUN 时，按提示授权安装 Sivio 网络服务。若端口被占用，在“网络设置 → 端口设置”换用空闲端口。

## 修复

- 识别运行期间 App 文件被替换或删除的情况，提示退出并打开完整副本，避免误导用户反复重装辅助服务。
- 修正正式打包后网络辅助工具的签名标识，保证与 helper 的身份校验规则一致。
- 保持现有稳定签名身份与更新公钥；新增 DMG 挂载、应用字节一致性、签名和隐私验证。
- ZIP 继续可用；`.app.tar.gz` 与 `.sig` 用于应用内更新。源码包不用于安装。

内部签名需要首次手动允许；Intel 未在本次发行范围内。自动化网络验证不等于人工授权弹窗和 TUN 的全面验收。
