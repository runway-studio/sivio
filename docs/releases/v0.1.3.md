# Sivio v0.1.3

修复网络服务续租和失效后的重连，统一 Sivio 网络辅助服务名称，并修正关于页 Logo。

## 更新内容

- 为续租握手提供更合理的等待时间，降低正常使用时因服务响应延迟出现会话失效的概率。
- 修正睡眠唤醒宽限期可能缩短剩余租约的问题；已过期的会话仍不能直接复活。
- 会话失效后尝试有界自动重连，保留用户停止意图，不抢占其他会话或外部系统代理。
- 网络辅助服务统一命名为 `sivio-helper`，同步更新安装、卸载、签名及升级路径；保留原有服务身份与配置。
- 关于页使用与侧栏一致的紫色 Sivio Logo，改进续租失败与重连状态提示。

## 安装与升级（Apple Silicon / M 系列 Mac）

1. 下载 `Sivio-0.1.3-aarch64.dmg`，完全退出旧版，将 `Sivio.app` 拖入 `Applications`。
2. 从“应用程序”打开新版，在网络设置中执行“安装 / 修复服务”，按 macOS 提示授权更新 helper。本版受管网络需要 helper revision 14，旧服务会显示更新 / 修复入口。
3. 重新启动网络。应用内更新的用户同样需要确认 helper 已升级。

ZIP 供手动安装；`.app.tar.gz` 与 `.sig` 供应用内更新；源码包与许可证随版本提供。

本版沿用内部签名，未经过 Apple 公证。首次打开若被系统拦截，请确认来自本仓库后，在“系统设置 → 隐私与安全性”中完成系统允许操作。Intel 不在本次发行范围内。
