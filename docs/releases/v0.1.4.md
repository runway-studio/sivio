# Sivio v0.1.4

- 工作台支持直接切换网络节点。切换后会刷新节点与连接状态，低频诊断按需加载。
- 改进网络中断后的恢复提示，区分正在重连、需要清理和需要手动处理的状态。
- 模型设置分别显示配置是否保存、客户端是否已读取以及模型是否已响应，方便定位接入问题。
- 收紧桌面布局，左侧图标栏从 64 px 减至 48 px，顶部位置栏从 44 px 减至 32 px，为正文留出更多空间。

## 安装与升级

本版适用于 Apple Silicon（M 系列）Mac。已有用户可在「设置 → 关于」检查更新，按提示下载、验签并重启。

首次安装请下载 `Sivio-0.1.4-aarch64.dmg`，退出旧版，将 `Sivio.app` 拖入「应用程序」，推出映像后再打开。应用沿用内部签名，尚未经过 Apple 公证。
