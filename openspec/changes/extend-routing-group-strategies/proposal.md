# Change: 路由组轮换、用量均衡与决策解释
## Why
用户要求继续实现 Routing groups；在已交付 Order 基础上继续实现可由现有数据可靠支持的调度策略。持续实施授权覆盖本阶段。
## What Changes
- 新增 Rotate 逐请求轮换和 Usage 按本机累计调度次数优先，保留 Order 默认与旧配置兼容。
- 调度状态按客户端及组持久化、事务化预留首选，备用调度也计数；失败与取消仍计入，不等同于计费或剩余额度。
- 决策记录展示策略、成员调度次数快照与排序原因。编辑页支持策略选择。
- 继续验证重启恢复、并发均衡、故障切换、客户端模型和凭据，以及独立目录打包。
## Impact
新增本机数据库调度表，需迁移；状态不参与 WebDAV 同步。成员配置变化重置计数和轮换位置，重命名与策略切换保留。Smart/Pace 需后续可靠账号额度与新鲜度数据；本阶段不增加此二策略或组嵌套。
