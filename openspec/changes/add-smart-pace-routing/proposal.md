# Change: Smart / Pace 额度路由
## Why
用户明确要求在现有路由组上继续实现 Smart / Pace、验证流程并打包。已有套餐查询可提供真实重置时间，但尚未按路由成员绑定并接入调度。
## What Changes
- 增加 Smart（有余量中最早重置优先）和 Pace（周剩余百分比/剩余小时优先）。
- 按供应商真实凭据及明确绑定的 ChatGPT 账号查询；增加短期进程缓存、并发合并、超时和配置隔离。
- 未支持、缺失、过期、查询失败或缺少周窗口时明确降级；耗尽成员置于末尾。
- 编辑器、Claude 模型菜单、决策依据展示策略与额度快照。
## Impact
model-routing；routing_groups、代理请求上下文、套餐查询、模型页、本地化、测试及内部打包。
