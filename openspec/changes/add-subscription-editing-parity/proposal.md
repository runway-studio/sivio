# Change: 补齐 Clash Verge 订阅操作和可视化增强编辑

## Why
用户明确要求迁移截图中的订阅菜单和可视化规则编辑能力。现有增强管线已存在，但入口集中在长表单中，缺少列表编辑、独立菜单、二维码和外部文件入口。

## What Changes
- 按现有完整迁移授权实施截图范围：使用、分享二维码、编辑信息/文件/规则/节点/代理组、订阅覆写/脚本、打开文件、直连/代理更新、删除，以及全局覆写/脚本入口。
- 可视化管理前置、原始、后置和删除项，支持搜索、顺序调整、恢复、YAML 高级编辑。
- 保存和切换正在运行的订阅使用现有事务回滚管线；验证后提交，保留外部代理所有权。
- 外部打开的是应用管理的私有 YAML 工作副本；显式读回并保存后生效，避免无提示覆盖配置。

## Impact
- Spec: network-proxy
- Code: 订阅编辑 React 组件、network profile API、增强管线、测试和内部分发包。
- 不修改 Clash Verge 的配置和运行状态，不公开分发。
