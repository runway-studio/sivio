## Decisions
- 复用 Recorder，增加进程内 LiveStore。ProxyService 持有并跨网关热重启共享，应用重启清空；请求和统计仅记录元数据。
- 页面每 750ms 获取原子快照，隐藏/离开页面暂停查询；短请求仍留在最近记录中，不伪造活动动画。
- 请求状态为 selecting/connecting/streaming/completed/failed/interrupted。响应头成功不等于完成；响应体 EOF 仅表示传输完成，不推断模型业务语义成功；读取错误或明确的协议错误信封归为 failed。
- 单请求唯一 ID；统计请求/曾切换成员的请求/最终转发或读取失败/中断分别累计。同成员格式重试不算改道；熔断跳过不算实际派发。
- 保留最多 256 个近期请求，优先保留活动请求；极端并发超限明确报告省略数。统计按 app/group 隔离，最多 512 个桶，超限明确标识。
- 活动 Recorder 最后引用销毁时终止请求，防止取消后残留动画。流式读取结束/取消触发状态更新。
- 限流仅展示上游 Retry-After 的恢复建议，不更改调度器或承诺服务可用。
- 现有持久化决策及配置不迁移，新增字段 serde default 兼容旧记录。
- 三栏默认布局；窄区域仅在图内横向滚动，不折叠为两栏。适配浅/深色、减少动态效果和键盘操作。
