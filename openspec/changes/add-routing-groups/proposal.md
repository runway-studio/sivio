# Change: 可选择的 Order 路由组
## Why
用户明确批准实现路由组基础闭环并验证后打包；现有供应商故障转移没有命名模型组。
## What Changes
- 模型菜单新增路由组管理，按客户端定义命名组和有序供应商/模型成员。
- 统一选择器可选择组；仅路由模式可用，直连与聚合保持原语义。
- 请求按组成员顺序执行，继承超时/熔断保护，不回写备用成员覆盖组选择。
- 决策记录包含组快照；Claude /model、启动恢复复用现有受保护写入。
## Impact
影响配置存储、模型目录、网关请求上下文与前端；无外部依赖。首版每组最多 10 个不同供应商，不支持组嵌套与高级策略。
