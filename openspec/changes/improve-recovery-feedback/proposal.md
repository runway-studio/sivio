# 网络恢复与模型生效反馈

用户于 2026-11-12 确认执行上一轮建议，优先完成稳定性验收、异常恢复和模型生效反馈；保持三栏布局。

## Why
网络自动重连和清理状态未完整传递到首页；模型保存后的提示覆盖就绪信息，难以分辨配置保存、客户端读取与模型响应验证。

## What Changes
- 将现有恢复流程进度和清理要求作为类型化快照字段暴露，不通过错误字符串推断。
- 概览/网络首页提供准确恢复提示和已有设置入口，保留有界重连及所有权保护。
- 模型页持续展示三个独立生效阶段，保存或打开客户端均不冒充客户端已读取；通过现有引导进入验证/打开客户端。
- 执行前端、原生隔离回归，尝试原生窗口验收并如实记录工具/设备限制。

## Impact
涉及 network runtime/lease 快照、NetworkHealth、模型页状态展示；不改变配置存储格式，不增加自动收费探测，不修改三栏布局。
