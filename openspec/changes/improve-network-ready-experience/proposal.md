# Change: 改善网络页面连续性、启动与服务授权体验

## Why
用户明确要求修复切页图表重置、打开后额外启动网络、正常更新反复安装修复服务的问题。本次按该明确实施请求执行。

## What Changes
- 流量历史按内核代次缓存，流量视图保持挂载，隐藏时不执行动画。
- 初始化后自动准备内核；已有其他系统代理时不抢占，用户打开系统代理才显式接管。
- 服务登记支持固定签名证书与严格应用标识，保留旧哈希兼容。首次升级旧登记需一次系统授权，之后同签名更新无需重新登记。
- 只有需要特权且服务异常时显示修复；用户启用时按需完成首次授权。

## Impact
涉及网络生命周期、React 流量页、原生 helper 信任校验。保留签名、IPC 身份、lease 与恢复边界，不使用宽泛 bundle ID 信任。
