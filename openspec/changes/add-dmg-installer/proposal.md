# Change: 内部签名 DMG 安装与恢复修复

## Why
用户要求保留内部签名，提供拖到 Applications 的 DMG，并修复旧运行目录丢失后的错误提示。

## What Changes
- 最终签名 App 生成只读 DMG，包含 Applications 快捷入口和首次允许说明。
- 发布前挂载核验 App 与签名原件一致，检查签名及隐私，纳入下载摘要与发布清单。
- 识别运行代码被删除并提示重新打开完整 App，发布新版本 v0.1.2。

## Impact
- 影响打包、发布和恢复提示；不更改 helper 信任模型。
- 本次会话用户已明确批准实施、推送 GitHub 及发布新版本。
