# Change: 落地三栏工作台 V2

## Why
用户已审阅三栏 V2 设计稿，并于 2026-11-11 明确要求「好的，开始落地吧」。本变更记录已授权的实施范围：保留三栏布局与导航，在概览、网络首页、模型选择内减少操作并准确反馈状态。

## What Changes
- 概览突出当前网络、连接方式、常用客户端和真实运行信息；网络首页保留已有功能和显示偏好。
- 复用当前 controller 接口提供可搜索的节点选择器；应用带 generation 防护，失败留在原选择并允许重试。
- 增加用户主动触发的网络检测摘要，区分服务运行、目标连通与模型响应，变更/切网/结果过期后不再展示旧成功。
- 模型页常用选择优先、高级目录保留，提供当前配置路径、保存反馈和切换客户端时的草稿保护。
- 不改变代理协议、服务权限、数据库、三栏宽度、原导航入口或发布渠道。

## Impact
- 新增 workspace-usability 增量；叠加 improve-ai-workspace-readiness 阶段 A，不推进其 B–D 范围。
- 主要涉及 Overview、NetworkHome、ModelPickerContent 及新增的业务展示/选择组件。
- 保留已有 revision/generation、未保存导航拦截与真实诊断确认。设计稿示例不进入生产；未接入的活动历史不伪造。
