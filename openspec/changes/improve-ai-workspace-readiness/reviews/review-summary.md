## 主要修订与关闭
| 主题 | 原问题 | 最终规则 |
| --- | --- | --- |
| 会话连续性 | 新旧保护范围矛盾、认证变化可能换键重选 | request/session和cursorProtection矩阵确定，认证版本放绑定值；未知归属显式拒绝 |
| 环境切换 | 既要求排空又要求在途热切，共享网关可能影响其他app | hot_policy单事务热切；文件变化按app准入/排空；snapshot恢复保留明确全局暂停 |
| 预算 | observe与零额冲突，旧消费可能清零，派发前持久边界缺失 | mode×限额表、启动opening/cutover、发送前pending、单行双scope、unknown核对及固定UTC offset |
| 配置协调 | 漏掉现有sync/Skills锁，存在倒序/重入风险 | 复用sync_mutex，gate→mode→Skills→短DB；under_guard入口及屏障外下载/回调 |
| 对象恢复 | 同ID替换活跃对象会留下缺凭据活动引用 | 活跃依赖缺秘密/引用在预览阻止；闲置可待补，不隐式改未选对象 |
| 验收可执行性 | 一需求多任务被误解为每任务验全部后续场景 | 68场景主责任表；B供应商预算、C方案归因，T18/T19/T20分工消除反向依赖 |
| 轻量取舍 | 时区/分位数留占位、聚合高基数 | 固定UTC offset与桶边界/样本断言，高频revision只保留于有界明细 |
