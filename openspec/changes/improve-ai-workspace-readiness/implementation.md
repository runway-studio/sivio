- T01/T02：新增start/cancel诊断命令、每客户端单实例Run、固定合成提示词、单候选/无重试、30秒总截止、256KiB响应上限、10分钟TTL。派发前后核对配置/凭据/出口/网络身份，取消和过期后拒收迟到结果。仅静态凭据受支持；托管OAuth/官方Codex及六个非网关客户端明确unsupported并给出手动路径。
- 探测使用已有供应商适配器的端点/鉴权和统一outbound策略；诊断专用client禁跟随重定向、禁网关自环；managed不可用不直连。不经过生产调度器/熔断器/会话粘性/用量写入；purpose=diagnostic、budgetEnforcement=not_enabled、costStatus=unknown明确返回。仅保存每客户端最后一条内存结果，重启后重新验证，不保存提示词/模型输出。
- T03：概览/网络首页共用被动快照和主动诊断结果，成功与运行分列；出错不沿用缓存成功值。两页可进入配置修复，401显示“修复授权配置”。前台5秒/诊断中1秒轮询只读事实，失焦不轮询；不会自动开始模型探测。
