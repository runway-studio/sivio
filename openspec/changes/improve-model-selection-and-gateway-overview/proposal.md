# 模型选择持久化与网关总览

## Why
路由配置中的 ANTHROPIC_MODEL 与 Claude Code /model 保存的 model 冲突；Sivio 退出再启动时重新投影还会丢失客户端选择。首页缺少客户端、网关、供应商之间的可视关系。

## What Changes
- 路由启动模型写入 model，移除接管配置的 ANTHROPIC_MODEL；直连供应商原始配置保持独立。
- 本机按供应商及路由/聚合模式记住客户端选择，和配置切换一起提交、恢复；显式修改供应商默认模型时使用新默认。
- 首页加入参考用户图片的三栏连接总览，展示真实客户端模式、网关地址及按来源分组的供应商，可进入现有管理入口。

## Scope
用户于本轮明确要求实现、完整验证并重新打包。复用现有代理能力，图中未实现的协议、账号、插件不作为已支持能力展示。
