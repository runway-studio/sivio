## ADDED Requirements

### Requirement: F19 订阅和配置档案
系统 SHALL 提供 订阅和配置档案，遵守 coverage.md 的客户端支持边界和 design.md 的权限、所有权及生命周期约定。

#### Scenario: F19-success 正常使用
- **WHEN** 用户在受支持的 macOS 环境中使用该能力，且必要依赖可用
- **THEN** URL/本地文件/链接导入、创建编辑复制排序删除、手动和定时更新，显示订阅使用量到期信息，配置预览及切换

#### Scenario: F19-failure 异常与边界
- **WHEN** 该操作出现无效输入、权限、依赖、并发或运行异常
- **THEN** 下载失败或 YAML 校验失败保留上次可用配置和激活指针；不同订阅同名节点不互相污染

### Requirement: F20 配置增强及规则节点编辑
系统 SHALL 提供 配置增强及规则节点编辑，遵守 coverage.md 的客户端支持边界和 design.md 的权限、所有权及生命周期约定。

#### Scenario: F20-success 正常使用
- **WHEN** 用户在受支持的 macOS 环境中使用该能力，且必要依赖可用
- **THEN** 支持全局和订阅 Merge/Script、规则/节点/代理组编辑；生成运行配置和处理日志；标明应用拥有字段的覆盖优先级

#### Scenario: F20-failure 异常与边界
- **WHEN** 该操作出现无效输入、权限、依赖、并发或运行异常
- **THEN** 脚本超时、非法规则、循环代理链不发布；运行配置可回退到上次有效快照

### Requirement: F21 节点代理组测速与链式代理
系统 SHALL 提供 节点代理组测速与链式代理，遵守 coverage.md 的客户端支持边界和 design.md 的权限、所有权及生命周期约定。

#### Scenario: F21-success 正常使用
- **WHEN** 用户在受支持的 macOS 环境中使用该能力，且必要依赖可用
- **THEN** 显示代理组、节点选择、延迟测试、规则/全局/直连模式、链式代理；重启恢复所选节点

#### Scenario: F21-failure 异常与边界
- **WHEN** 该操作出现无效输入、权限、依赖、并发或运行异常
- **THEN** 节点失效或测速超时显示独立错误；组被订阅更新删除时按该组策略回退并通知

#### Scenario: 分组并发测速与吸顶
- **WHEN** 用户对代理分组发起延迟测试或滚动浏览大量节点
- **THEN** 使用有界逐节点请求并独立呈现测速中、实测延迟与错误；单个失败不影响其他节点，测速期间仍可选择节点或停止网络
- **AND** 切换运行代次、测速地址或离开页面时停止排队并丢弃迟到结果；分组标题滚动吸顶，支持常用分组置顶、排序、折叠和定位当前节点，分页保持渲染上限

### Requirement: F22 系统代理PAC和守卫
系统 SHALL 提供 系统代理PAC和守卫，遵守 coverage.md 的客户端支持边界和 design.md 的权限、所有权及生命周期约定。

#### Scenario: F22-success 正常使用
- **WHEN** 用户在受支持的 macOS 环境中使用该能力，且必要依赖可用
- **THEN** 按网络服务启停 HTTP/SOCKS/PAC 和守卫、设置绕过项、复制终端代理变量，UI 展示实际系统状态

#### Scenario: F22-failure 异常与边界
- **WHEN** 该操作出现无效输入、权限、依赖、并发或运行异常
- **THEN** 用户或其他 App 改变系统代理时暂停争抢并提示；退出仅恢复本 App 仍拥有的设置

### Requirement: F23 TUN权限服务与修复
系统 SHALL 提供 TUN权限服务与修复，遵守 coverage.md 的客户端支持边界和 design.md 的权限、所有权及生命周期约定。

#### Scenario: F23-success 正常使用
- **WHEN** 用户在受支持的 macOS 环境中使用该能力，且必要依赖可用
- **THEN** 安装/启动/停止/修复/卸载独立 helper，授权后启用 TUN 并验证 DNS/路由，支持普通 sidecar 降级

#### Scenario: F23-failure 异常与边界
- **WHEN** 该操作出现无效输入、权限、依赖、并发或运行异常
- **THEN** 拒绝权限仍可使用普通代理；未知客户端身份/任意可执行路径被拒绝；服务故障不假报 TUN 正常

### Requirement: F24 DNS端口LAN和高级网络设置
系统 SHALL 提供 DNS端口LAN和高级网络设置，遵守 coverage.md 的客户端支持边界和 design.md 的权限、所有权及生命周期约定。

#### Scenario: F24-success 正常使用
- **WHEN** 用户在受支持的 macOS 环境中使用该能力，且必要依赖可用
- **THEN** 支持 DNS 编辑校验/覆盖、端口、接口、IPv6、LAN、日志级别、TUN 可配置参数和上游 macOS 高级设置

#### Scenario: F24-failure 异常与边界
- **WHEN** 该操作出现无效输入、权限、依赖、并发或运行异常
- **THEN** 端口被占用时不杀外部进程；LAN 默认关闭；无效 DNS 不覆盖最后有效配置


#### Scenario: 独立网络设置与兼容端口
- **WHEN** 用户进入网络设置
- **THEN** 端口、TUN、系统代理、LAN、DNS、IPv6、统一延迟、日志、内核、控制器、测速、检测与增强分别提供独立编辑和保存；AI 出站设置在模型路由设置中，网络保存不提交模型策略
- **AND** 混合代理默认 7890，旧默认 15722 迁移为 7890，自定义端口保留，端口占用不得终止外部进程；监听端口与 AI 路由保持独立

#### Scenario: 运行中保存并自动应用设置
- **WHEN** 用户在 Sivio 网络运行时保存端口、DNS、LAN、代理或其他网络设置
- **THEN** 系统 SHALL 校验完整候选配置和端口，在串行生命周期边界内自动重新应用，确认运行就绪后保存设置；停止状态保存保持停止
- **AND** 应用失败或配置提交失败 MUST 保持旧配置并清理候选、恢复旧活动订阅及运行状态；恢复失败须报告实际失败并保留可清理的状态，不假报成功

#### Scenario: 保存预检和并发失败
- **WHEN** 候选配置无效、端口被其他进程占用或编辑版本已经过期
- **THEN** 系统 SHALL 在停止旧网络之前拒绝保存，保留编辑草稿和原运行状态，不终止占用端口的外部进程
- **AND** 保存请求串行执行，前端在应用期间禁止重复提交；无关设置保存和失败回滚不得抢回外部已修改的系统代理

#### Scenario: 外部关闭系统代理不影响独立内核
- **WHEN** SI Assist 在自有端口运行，Clash Verge 或其他外部操作关闭或修改 macOS 系统代理
- **THEN** SI Assist 保留内核、端口和租约，不把代理所有权变更报告为内核失败；保留外部修改并提示自动接管已暂停
- **AND** 用户可显式重新应用系统代理，使用当前会话与 generation，更新回滚基线而不重启内核；停止时清除旧守卫提示

#### Scenario: 已关闭连接不误判为端口占用
- **WHEN** SI Assist 停止后立即重新启动，旧连接仍在 TIME_WAIT
- **THEN** 可复用端口不误报占用；实际监听进程仍受到保护，启动失败时说明冲突端口且不终止该进程

### Requirement: F25 连接流量日志与规则观察
系统 SHALL 提供 连接流量日志与规则观察，遵守 coverage.md 的客户端支持边界和 design.md 的权限、所有权及生命周期约定。

#### Scenario: F25-success 正常使用
- **WHEN** 用户在受支持的 macOS 环境中使用该能力，且必要依赖可用
- **THEN** 展示实时流量、连接搜索/详情/单个和全部关闭、匹配规则及日志过滤，后台缓冲有上限

#### Scenario: F25-failure 异常与边界
- **WHEN** 该操作出现无效输入、权限、依赖、并发或运行异常
- **THEN** 断开内核显示过期状态并重新订阅；关闭页面取消订阅，不能重复累计流量

#### Scenario: 流量与内存独立采样
- **WHEN** 流量页打开且内核运行，内存流等待其有效帧或暂时失败
- **THEN** 流量独立按内核约一秒的节奏刷新，内存降低频率读取；等待期间不持有网络运行状态或 helper 生命周期锁
- **AND** 读取前后核对运行代次和受管会话，停止或重启后的迟到响应不能混入新运行数据

#### Scenario: 平滑滚动与采样生命周期
- **WHEN** 用户观察最近一分钟的实时上传下载曲线
- **THEN** 曲线按真实时间间隔平滑滚动、最多保留 60 点，不对缺失区间虚构流量；速度和累计值使用内核数据
- **AND** 仅图表路径逐帧更新；后台遵守暂停采样偏好并停止动画，离开页面停止新请求并释放绘制资源；系统减少动态效果时静态绘制

系统 SHALL 提供 内核版本启停与升级，遵守 coverage.md 的客户端支持边界和 design.md 的权限、所有权及生命周期约定。

#### Scenario: F26-failure 异常与边界

- **THEN** 下载摘要/架构错误或新内核启动失败时恢复旧版本；不得同时启两个占同端口内核

### Requirement: F27 网络和媒体可用性检测
系统 SHALL 提供 网络和媒体可用性检测，遵守 coverage.md 的客户端支持边界和 design.md 的权限、所有权及生命周期约定。

- **THEN** 提供上游检测列表、单项/批量检测、取消和结果时间，区分区域、连通、未知及受限制

### Requirement: 网络首页聚合
系统 SHALL 在网络二级菜单提供首页，参考固定上游 Clash Verge 首页，将订阅、当前节点、系统代理/TUN、代理模式、流量、连通性检测、出口 IP、内核信息和系统信息接入已有网络能力，并允许持久化选择显示的卡片。

#### Scenario: 首页快捷操作与真实状态
- **WHEN** 用户从网络首页修改系统代理、TUN 或代理模式
- **THEN** 使用快照版本调用同一设置事务，禁止重复提交；成功刷新快照，失败显示具体错误并保留实际旧状态
- **AND** 当前节点切换携带 generation，订阅更新复用已有事务，运行时禁止尚不支持的跨订阅切换并说明原因

#### Scenario: 首页检测与隐私
- **WHEN** 首页发起默认连通性检测或出口 IP 查询
- **THEN** 请求必须通过 Sivio 当前内核的显式代理，停止或代次改变拒绝结果，不允许静默直连；默认检测最多四个并发
- **AND** 出口 IP 默认隐藏且不写入持久化缓存，查询失败显示不可用；停止网络后不展示旧运行数据，离开或隐藏卡片后停止新的采样请求
