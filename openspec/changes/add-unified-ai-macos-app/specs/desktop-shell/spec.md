## ADDED Requirements

### Requirement: F01 统一应用与导航
系统 SHALL 提供 统一应用与导航，遵守 coverage.md 的客户端支持边界和 design.md 的权限、所有权及生命周期约定。

系统 SHALL 使用「概览 / 网络 / 模型」一级领域栏、沿用现有菜单样式的二级目录和右侧功能内容组成三栏布局。网络包含原 Clash 功能，模型包含原 CC Switch 功能；领域切换只改变视图，不改变服务运行状态。细节以 design/navigation-v3/interaction-design.md 为准；本修订已接入正式 App，验证范围见实施报告。

#### Scenario: F01-success 正常使用
- **WHEN** 用户在受支持的 macOS 环境中使用该能力，且必要依赖可用
- **THEN** 在一个主窗口和托盘访问 AI 与网络功能，切换页面保留状态，无需安装原版两个 GUI

#### Scenario: F01-failure 异常与边界
- **WHEN** 该操作出现无效输入、权限、依赖、并发或运行异常
- **THEN** 重复启动只激活现有实例，窗口重建不启动第二个内核

#### Scenario: F01-domain-memory 领域往返与内容一致
- **WHEN** 用户依次选择模型的 Codex、网络的节点，再往返两个领域
- **THEN** 分别恢复 Codex 和节点，一级高亮、二级高亮、面包屑与内容一致；AI 路由和网络运行不受导航影响

#### Scenario: F01-navigation-edit-guard 未保存编辑和兼容入口
- **WHEN** 有未保存表单时用户切换领域或通过搜索、设置返回、托盘定位其他页面
- **THEN** 先执行共用的离开提醒；取消或保存失败留在原页，确认离开后统一更新两级导航；旧入口仍定位到对应功能

#### Scenario: F01-directory-collapse 二级目录收起与设置返回
- **WHEN** 用户在 960×720 或更大的窗口收起二级目录、打开应用设置并返回
- **THEN** 一级三领域保持可见，目录图标有完整名称提示且应用设置可达；返回恢复来源领域和页面，窗口无整页水平溢出

#### Scenario: 网络目录控制与窗口拖动
- **WHEN** 用户在网络的任意二级页面查看或操作网络，或在窄窗口出现垂直滚动条
- **THEN** 二级目录不产生横向滚动；唯一启停入口位于网络二级目录并共享同一运行状态，失败可见且允许重试
- **AND** 三级内容顶部的非交互区域支持拖动窗口，按钮、输入和选择控件仍正常操作；读取失败不反复自动触发系统授权

### Requirement: F02 窗口托盘与快捷键
系统 SHALL 提供 窗口托盘与快捷键，遵守 coverage.md 的客户端支持边界和 design.md 的权限、所有权及生命周期约定。

#### Scenario: F02-success 正常使用
- **WHEN** 用户在受支持的 macOS 环境中使用该能力，且必要依赖可用
- **THEN** 关闭隐藏、开机自启、静默启动、轻量模式、菜单与快捷键均可配置；托盘能切换支持的供应商及网络节点

#### Scenario: F02-failure 异常与边界
- **WHEN** 该操作出现无效输入、权限、依赖、并发或运行异常
- **THEN** 销毁再建窗口不丢设置或重复订阅事件；快捷键冲突显示失败原因

### Requirement: F03 外观语言和编辑体验
系统 SHALL 提供 外观语言和编辑体验，遵守 coverage.md 的客户端支持边界和 design.md 的权限、所有权及生命周期约定。

#### Scenario: F03-success 正常使用
- **WHEN** 用户在受支持的 macOS 环境中使用该能力，且必要依赖可用
- **THEN** 支持主题明暗、颜色、图标、受限 CSS 和基线语言包，中文英文关键流程无缺词；表单离开提醒未保存，YAML 编辑有诊断和补全

#### Scenario: F03-failure 异常与边界
- **WHEN** 该操作出现无效输入、权限、依赖、并发或运行异常
- **THEN** 无效 CSS 可一键恢复；超大或错误 YAML 不阻塞整个窗口

#### Scenario: 参考配色的三级工作区
- **WHEN** 用户打开浅色模式下的概览、网络、模型或设置
- **THEN** 一级为浅灰图标栏，二级为灰白目录，三级为白色内容；二、三级共享细边框圆角工作区，原紫色主操作与选中状态保留
- **AND** 统一顶栏保留原生窗口按钮空间并支持非交互区域拖动，目录收起和窄窗口无水平溢出；深色模式提供相应中性底色且主色不变

### Requirement: F04 更新关于与诊断入口
系统 SHALL 提供 更新关于与诊断入口，遵守 coverage.md 的客户端支持边界和 design.md 的权限、所有权及生命周期约定。

#### Scenario: F04-success 正常使用
- **WHEN** 用户在受支持的 macOS 环境中使用该能力，且必要依赖可用
- **THEN** 一个应用更新入口，展示版本、变更记录、来源许可、诊断导出；自己的签名包更新后保留数据

#### Scenario: F04-failure 异常与边界
- **WHEN** 该操作出现无效输入、权限、依赖、并发或运行异常
- **THEN** 未配置更新源显示不可用；错误签名/架构包被拒绝且旧应用可继续使用
