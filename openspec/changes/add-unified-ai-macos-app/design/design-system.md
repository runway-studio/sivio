# 视觉与交互规范

## 方向
macOS 本地工作台：白色窗口、冷灰卡片、近黑文字和克制的紫色交互强调。参考用户提供的 iTokens 截图及 `ai-token-desktop/src/renderer/src/ui.css` 的实际生效样式；该文件在旧 `styles.css` 之后加载，因此采用当前紫色方案。绿色仅表示健康/成功，紫色表示操作/选中，避免混淆。

参考来源：[用户截图](references/itokens-color-reference.png)；外部参考项目的 `src/renderer/src/ui.css`（不随本仓库提供）。只读取参考项目，没有修改其文件。深色主题为本稿基于相同语义的适配，不声称来自参考项目。

颜色不是唯一状态提示。正常/关闭/失败/未授权必须同时有文字。正文 text、muted 与实际背景组合在交付时应达到 4.5:1；图表两组数据同时由位置和图例区分，浅灰系列在正式实现中仍需增强线型/数据读取等非颜色提示。

## 布局与密度
- 基准画布1440×1000，支持1024×768紧凑窗口。侧栏218px，顶栏67px，主区边距32px。
- 8px为主要间距节奏，4px用于局部微调；卡片间距16px，主区段间距24px。
- 标题26px/600，区块标题15px/600，内容12–14px，元数据10–11px。正式桌面实现需响应系统缩放；移动端不是本次产品目标。
- 字体优先 Helvetica Neue、PingFang SC，与参考项目保持一致。卡片半径10–12px，按钮7px，对话框16px。只给浮层明显阴影，不给每张卡片悬浮效果。
- 表格用于批量资源与配置，卡片用于供应商、节点和项目；避免所有对象统一做成大卡片。
- 主要操作只保留一个紫色按钮，危险动作独立二次确认，运行失败提供恢复路径。

## 导航
三组侧栏：工作空间、AI资源、网络。工具特有能力进入二级页，不把十个工具和所有子功能全部摊在一级侧栏。网络页内用节点/订阅/规则/连接/日志页签。

⌘K打开页面搜索，⌘,进入设置。选中导航同时有底色、字重及aria-current。侧栏底部固定设置和本地身份，不做云账号伪装。

## 控件与反馈
- 输入框必须有可见标签；校验错误在字段附近，保留输入；密码默认遮罩。
- 模式页签只切换查看，必须点应用才改变当前模式。官方订阅不支持的模式阻止继续并解释。
- TUN必须经过权限说明，允许/拒绝状态都能继续操作；系统代理、TUN、AI出站不能共用一个含糊的“连接”开关。
- 导入是选择来源→预览→完成；同名配置保留来源，导入不等于立即启用系统代理。
- 弹窗用原生dialog管理焦点，Escape关闭，关闭后恢复触发点；toast使用aria-live，不能遮挡主要内容。
- 160ms轻量状态动画，遵循prefers-reduced-motion。长任务在正式实现增加进度、取消和错误恢复，不能用瞬时成功替代。

## 图形与图表
图标为同一套1.6px线宽SVG。工具缩写是占位，不复制官方品牌标识。图表展示示例趋势，正式实现需补充真实量纲、刻度、图例、键盘可读取的数据表及无数据状态；原型不作为统计准确性依据。

## 品牌标志
侧栏使用 `logo/si-assist-mark.svg`，40×40 px 容器、透明底色；邻接 SI Assist 字标时图形作为装饰，不重复朗读。favicon 和 macOS 应用图标使用白色圆角底板版本。主色 #7055D8、辅色 #9D87E8，浅深色共用已确认轮廓；不要拉伸、加描边或随主题反转色相。可编辑母版与导出目录见 [Logo 说明](logo/README.md)。
