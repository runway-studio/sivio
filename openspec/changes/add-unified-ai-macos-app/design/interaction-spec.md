# 核心流程与交互边界

## 可评审流程

| 流程 | 操作入口 | 可体验路径 | 关联任务 |
| --- | --- | --- | --- |
| 首次接入 | 概览→接入已有配置 | 来源勾选→预览/冲突处理→确认→不自动启用代理 | T07 |
| 新供应商 | AI工具→添加供应商 | 空字段错误→HTTPS地址校验→保存示例→列表出现 | T08 |
| 供应商切换 | AI工具→其他供应商启用 | 配置预览→确认→使用中状态；亦可模拟外部冲突 | T08/T06 |
| 模式切换 | AI工具→直连/路由/聚合 | 先查看，后应用；不支持组合不显示；官方不兼容时解释 | T11/T19 |
| 网络连接 | 网络代理→节点 | 节点选中→延迟提示；停止需确认，不隐式直连 | T10/T14 |
| TUN授权 | 网络代理→TUN | 权限说明→拒绝仍可普通代理；允许更新模拟状态 | T16 |
| 扩展同步 | MCP/Skills→管理同步 | 选择支持工具→确认同步反馈 | T17 |
| 会话阅读 | 会话历史 | 搜索标题→切换详情→查看恢复/导出说明 | T21 |
| 外观 | 左下角月亮 / 设置主题 | 浅深色切换，页面布局保持 | T25 |

## 本轮实际修订
1. 按工具限制路由/聚合模式，不给Gemini展示聚合按钮；共存型工具展示共存配置。
2. Anthropic官方配置选择路由/聚合时显示限制，防止设计暗示不支持的能力。
3. 核心停止后不能直接开启系统代理或TUN，提示先启动核心。
4. 导入没有勾选来源时阻止继续；预览按所选来源变化。
5. 明确区分“可达”和“密钥/模型有效”，探测反馈不假装请求成功。
6. 网络流量曲线标注过去60秒，避免与今日用量趋势混淆。

## 原型限制
- 资源操作只修改页面内存/DOM；某些说明型表单关闭即结束，不会添加真实资源。
- AI工具下拉使用少量演示供应商，不代表完整预设、模型目录或每个工具的最终字段。
- 授权、剪贴板、终端、文件导出、安装、云同步只展示说明或模拟反馈。不会调用系统接口。
- 部分高级编辑器、取消/加载状态、空状态、错误状态未逐页展开；实施中必须依据spec补齐，不能以原型缺失为由删掉需求。
- 窗口红黄绿为macOS视觉装饰，正式Tauri使用系统窗口控件。
- 概览是已有配置的示例状态（系统代理开启、TUN关闭），不代表产品首次安装默认值；首次安装应关闭全部接管。

## 评审建议顺序
先看概览与侧栏能否找到常用操作，再查看AI工具与网络页的分工；依次体验切换冲突、TUN拒绝和导入预览，最后切换深色及紧凑窗口。后续若调整视觉，优先改tokens和共享组件，避免每页各自微调。
