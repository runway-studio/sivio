# 验收与可行性边界

## 规划完成标准
1. OpenSpec strict 验证成功；需求—任务—阶段映射、任务依赖DAG及相对文档链接检查通过。
2. 用户确认的完整集成范围有固定源码基线、排除项和客户端支持表。
3. 三道质量门无未解决的规划P0/P1。运行/权限/签名验证列为实施任务，不将静态阅读写成完成证明。
4. 本轮只新增规划与OpenSpec配置文档；tasks.md没有已完成产品任务。

## 真实产品完成标准
- F01–F36及T01子功能台账全部有测试/真机证据；0个P0/P1，P2有影响和负责人。
- macOS12及交付时最新受支持macOS，在Apple Silicon与Intel可运行。至少最低版本与最新版本、两架构均有真机或可复现硬件环境结果；构建通过不替代权限测试。
- 两个原版GUI不运行时，本App可独立完成所有范围内动作；外部CLI仍按其自身安装要求存在，App不实现CLI本体。
- 默认不启用TUN、系统代理、LAN、自动同步或实验账号接入；启用须显式操作。拒绝权限不能破坏普通功能。
- 签名/公证和helper授权使用独立测试环境；本轮不接触用户证书或真实网络设置。

## 功能与协议测试
每个客户端使用脱敏配置fixture，覆盖已有配置、空配置、非法配置、未知字段/注释、目录覆盖、权限不足和外部修改。流式测试包含工具调用、多模态支持矩阵、断流、取消和错误；只对基线声明支持的协议方向承诺对等。

连通检测是网络可达测试，不声称验证Key和模型。真实请求验收需要测试账号；合成fixture可完成开发自测但不能冒充live证据。AI消费测试使用最小请求和预算上限，执行前由实施方配置。

## 资源和响应目标（待实施测量，不是现状）
固定基准：Apple Silicon 16GB；记录具体机型、OS、模式、样本和5次冷启动数据。Intel记录单独结果。
- 冷启动至主界面可操作p95≤5秒；不等待订阅或外部API完成才显示界面。
- 缓存列表切换p95≤200ms；10,000会话、1,000节点分页/虚拟化操作不超过1秒主线程冻结。
- idle 10分钟：关闭活跃流量/检测/同步后，应用及受管进程总CPU均值≤5%一个核心，总RSS≤600MiB；轻量模式≤350MiB。超出需先分析采样，不通过单纯隐藏窗口谎报。
- 连续20次打开/销毁窗口后，等待稳定30秒，进程和事件监听器数量不增加，稳定RSS相对首轮增长≤15%。
- 日志默认保留7天且总量≤200MiB，超限轮转；请求正文和完整会话不进入诊断日志。会话源文件不被日志轮转删除。
- AI额外转发开销在本地mock、单并发、100请求非流式测试中p95≤50ms，不包含上游耗时；并发20流式运行10分钟无串流、丢帧或不可取消请求。

## 资源与外部依赖
- 需macOS开发机、Xcode命令行工具、两架构构建/验收环境，测试用AI账号和订阅、WebDAV/S3 fixture服务；当前未验证这些资源已齐全。
- 当前机器曾遇磁盘不足，本轮检查约6.1GiB可用；建议实施构建前至少预留30GiB，并由T02记录实际空间需求。这不阻止文档规划，可能阻止本机编译。
- 内部受控试用与对外分发是不同门槛；证书、更新服务、最终许可策略在T28/外部分发前确定。没有这些资源仍可开发与本地测试，但不能宣称已交付签名安装包。

## 风险分类
规划阻塞：未决定关键架构/范围，或任务无法描述输入和成功结果。实施验证依赖：有明确验证方法、责任与失败停止点，尚未执行。发布阻塞：证书/许可/更新源等未完成。不得用“剩余风险”隐藏实际无法开始的核心决策，也不得把所有待做测试都误当成规划阻塞。

## 第二版新增关键验收
- 首块输出后断流不跨供应商拼流；副作用请求不自动重放；供应商切换不改变正在处理请求的快照。
- 加密备份错误口令/篡改不写活动目录；SQL导入禁止ATTACH/extension；受管内核拒绝越界资源路径。
- 主进程和helper先后强杀后，用真机验证launchd重启、lease过期与所有权恢复；服务被用户彻底禁用时验证离线恢复指引可用。
- 安装器不可回滚时不得对外承诺原版本必然保留；已支持来源仍保留安装/升级入口，首次提示影响；失败显示修复状态，未知来源不覆盖。
